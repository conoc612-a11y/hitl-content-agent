# HITL 콘텐츠 발행 에이전트

뉴스레터, 블로그, 마케팅 문구, SNS 글처럼 외부에 나가는 콘텐츠를 자동으로 만들되, 위험한 글만 발행 직전에 사람에게 승인받는 Streamlit 데모입니다.

실제 서비스로 치면 다음 상황에 쓰는 에이전트입니다.

- 뉴스레터를 구독자에게 보내기 전 검수
- 블로그 글을 공개 발행하기 전 승인
- 마케팅 문구를 캠페인 페이지에 올리기 전 승인
- SNS 글을 예약 발행하기 전 승인

## 주제

콘텐츠 자동 발행 승인 에이전트

- 입력: 발행하고 싶은 글 요청 원문
- 에이전트 작업: 초안 생성, 위험 기준 검수
- 외부 반영 단계: 실제 서비스에서는 뉴스레터/블로그/SNS 발행, 이 데모에서는 `data/published.jsonl`에 발행 완료 기록 저장
- HITL 지점: 발행 완료 기록 저장 바로 직전

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 다음 순서로 확인합니다.

1. `새 요청 처리` 탭에서 요청 원문을 입력합니다.
2. 안전한 건은 자동으로 `발행 완료`에 저장됩니다.
3. 위험 기준에 걸린 건은 `승인 대기`에 저장됩니다.
4. `승인 대기` 탭에서 한 건을 열어 이유를 확인하고 `승인` 또는 `반려`를 누릅니다.

## 빠른 테스트 입력

자동 발행 예시:

```text
신규 기능 업데이트 안내. 사용자는 설정 화면에서 알림을 켤 수 있습니다.
```

승인 대기 예시:

```text
이번 캠페인은 전환율 35% 상승을 무조건 보장합니다.
```

## 자체 검증

```bash
python pipeline.py
```

성공하면 `self_check passed`가 출력됩니다.

## 파일 구조

```text
hitl-content-agent/
  app.py            # Streamlit 웹 데모
  pipeline.py       # 초안 생성, 검수, 체크포인트, 승인/반려 로직
  requirements.txt
  README.md
  REPORT.md
  docs/
    demo-screen.svg # 데모 화면 캡처 대체 이미지
```

## 저장 파일

실행 중 아래 파일이 자동 생성됩니다.

- `data/pending.json`: 승인 대기 체크포인트
- `data/published.jsonl`: 자동 발행 및 승인 발행 기록
- `data/rejected.jsonl`: 반려 기록
- `data/audit_log.jsonl`: 멈춤, 승인, 반려 이벤트 기록

API 키나 외부 서비스는 사용하지 않습니다.
